# Project Context

## Project Type

Modern responsive business/e-commerce website.

## Design Goal

Create a polished, premium, modern Indian festive retail experience.

The website should combine:

- Festive visual identity
- Modern commercial design
- Clear product discovery
- High-conversion interactions
- Strong trust and safety communication
- Responsive usability

## Themes

The website supports two complete visual themes:

- Light Theme
- Dark Theme

Theme specifications:

- `.impeccable/context/light-design.md`
- `.impeccable/context/dark-design.md`

Do not merge or reinterpret these theme specifications.

## Design Philosophy

The interface should feel:

- Premium
- Festive
- Modern
- Trustworthy
- Commercial
- Clear
- Responsive
- Easy to scan

Avoid unnecessary visual complexity.

## User Experience

Users should be able to quickly:

1. Understand the business
2. Discover products/categories
3. Search and filter products
4. Understand pricing and offers
5. Identify certifications and safety information
6. Add products to the cart
7. Review quantities and pricing
8. Continue toward checkout/contact/order flow

## Responsive Requirements

Support:

- Desktop: 1200px+
- Tablet: 768px–1199px
- Mobile: below 768px

Mobile is not a reduced desktop layout.

Reflow content intentionally for touch interaction.

## Implementation Principles

- Use reusable components.
- Avoid duplicated UI.
- Use semantic HTML.
- Use theme tokens instead of arbitrary colors.
- Preserve the approved visual design.
- Keep interactions predictable.
- Prioritize accessibility.
- Keep layouts performant.

## Do Not

Do not:

- Invent a different visual style.
- Introduce unrelated colors.
- Replace the selected typography.
- Add excessive gradients.
- Add unnecessary animations.
- Use generic template-looking layouts.
- Mix Light and Dark theme tokens.
- Redesign an approved screen while implementing it.
