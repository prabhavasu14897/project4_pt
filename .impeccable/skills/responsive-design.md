# Responsive Design Skill

## Purpose

Create layouts that work intentionally across desktop, tablet, and mobile.

---

## Breakpoints

Use the breakpoints defined by the design system:

- Desktop: 1200px+
- Tablet: 768px–1199px
- Mobile: below 768px

---

## Desktop

Prioritize:

- Efficient use of horizontal space
- Clear product grids
- Multi-column layouts
- Persistent navigation where appropriate
- Comfortable content density

---

## Tablet

Reflow layouts instead of simply shrinking them.

Check:

- Navigation
- Product grids
- Tables
- Forms
- Filters
- Modals
- Cards

---

## Mobile

Prioritize:

- Touch-friendly controls
- Readability
- Simple navigation
- Appropriate card widths
- Horizontal scrolling where designed
- Bottom sheets/drawers where appropriate

Never allow:

- Horizontal page overflow
- Tiny text
- Unusable buttons
- Overlapping content
- Broken grids

---

## Testing

Every major screen must be checked at:

- 1440px
- 1200px
- 1024px
- 768px
- 390px
- 375px

Fix layout problems rather than adding one-off hacks.
