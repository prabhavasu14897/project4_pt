# Image Reference Context

## Purpose

Provided images are approved visual assets and references for the website.

Use them whenever they correspond to the screen design.

---

## Image Sources

Reference assets are organized under:

`/images/`

Recommended folders:

- `/images/logo/`
- `/images/products/`
- `/images/banners/`
- `/images/icons/`
- `/images/decorative/`

---

## Image Rules

Use the provided image assets instead of generating replacements when an appropriate asset exists.

Do not:

- Replace an approved image unnecessarily.
- Change the image composition.
- Add unrelated stock imagery.
- Use placeholder images when an approved asset exists.

---

## Image Treatment

Preserve the visual treatment shown in the screen:

- Aspect ratio
- Cropping
- Object positioning
- Border radius
- Background
- Image container size
- Overlay
- Gradient treatment

---

## Product Images

Product images must maintain consistent:

- Aspect ratio
- Container dimensions
- Alignment
- Object-fit behavior

Avoid inconsistent image sizing between cards.

---

## Logos

Use the provided logo assets.

Do not recreate or approximate the logo using text.

---

## Decorative Images

Decorative imagery should support the approved visual hierarchy.

Do not add decorative images merely to fill empty space.

---

## Performance

Use appropriate image formats and responsive image loading.

Prefer optimized images and lazy loading for below-the-fold content.
