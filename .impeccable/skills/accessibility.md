# Accessibility Skill

## Purpose

Ensure the interface remains usable and understandable for all users.

---

## Semantic HTML

Prefer semantic elements:

- header
- nav
- main
- section
- article
- footer
- button
- form
- label

Do not use clickable divs when a button or link is appropriate.

---

## Keyboard

All interactive functionality must be usable with a keyboard.

Focus states must remain visible.

---

## Forms

Every input must have an associated label.

Validation errors must be understandable without relying only on color.

---

## Color

Never communicate important information through color alone.

Use:

- Text
- Icons
- Labels
- Patterns
- Appropriate semantic states

---

## Touch

Interactive controls must have comfortable touch targets on mobile.

---

## Images

Images must have meaningful alternative text when they communicate information.

Decorative images should not create unnecessary screen-reader content.
